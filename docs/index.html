Quick start

Connect and go.

Hermes Mobile connects to the Hermes dashboard you already run.

1

Install Hermes Mobile

Get it from F-Droid, Obtainium, or the latest GitHub release.

2

Start your Hermes dashboard

Run hermes dashboard --host 0.0.0.0 on the machine hosting Hermes.

3

Sign in from your phone

Enter the dashboard host and port. Hermes Mobile detects the available authentication method and handles the rest.
