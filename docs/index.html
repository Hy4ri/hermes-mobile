Theming

6 built-in color presets plus Material You dynamic colors on supported devices.

Screenshots

Chat, cron, Kanban, and skills screens.

Quick start

Point the app at your Hermes gateway and go.

  1. Install from F-Droid, Obtainium, or GitHub Releases.
  2. Start your dashboard on the host: hermes dashboard --host 0.0.0.0
  3. Tap Sign in, enter the host and port — the app auto-detects the auth mode.
